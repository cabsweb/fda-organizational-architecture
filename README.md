# fda-organizational-architecture
FDA Organizational Architecture — Summer internship project mapping and visualizing FDA centers, offices, divisions, reporting structures, therapeutic areas, and drug-review responsibilities using official sources, source links, and update dates.

## Useful resources

### FDA organization and reporting structure

- [FDA Organization](https://www.fda.gov/about-fda/fda-organization) — primary overview of the agency organizational structure.
- [FDA Organization Charts](https://www.fda.gov/about-fda/fda-organization/fda-organization-charts) — center, office, and division organization charts.
- [FDA Overview Organization Chart](https://www.fda.gov/about-fda/fda-organization-charts/fda-overview-organization-chart) — high-level agency structure.
- [Office of the Commissioner](https://www.fda.gov/about-fda/fda-organization/office-commissioner)

### Project source-tracking practice

For each organizational relationship or review responsibility captured in the map, record the official FDA source URL, the relevant page or chart title, and the date last checked. This keeps the architecture transparent and makes organizational changes easier to audit.
